# 현장 라벨링 매뉴얼 (처음 하는 사람용)

라이브 앱에서 **SAM**으로 박스/토트/슈링크랩/팔레트를 라벨해 학습 데이터를 모으는 방법입니다.
마우스로 객체를 한 번 감싸면 AI(SAM)가 알아서 외곽선을 따줍니다. 어렵지 않아요.

---

## 0. 왜 하나요?

모델이 **현장에서 놓치거나 헷갈리는 장면(하드케이스)** 을 몇 장 라벨해서 추가 학습하면,
그 약점이 메워집니다. "잘 잡는 장면"보다 **"못 잡는 장면"을 모으는 게 핵심**이에요.

---

## 1. 실행 & 라벨링 켜는 법 (Thor, NoMachine) ★중요

NoMachine으로 Thor 데스크톱 접속 → 터미널에서 둘 중 하나로 실행합니다.
**실행 도구에 따라 라벨링을 켜는 방법이 다릅니다:**

### 방법 A — GUI (평소 쓰는 데모 도구)
```bash
bash ~/demo_gui.sh
```
- 화면에 **영상이 나온 상태**에서, 왼쪽 패널의 **`✎ 라벨링(SAM)` 버튼을 클릭**합니다.
- ⚠️ 영상이 아직 안 뜬 상태(검출 전)면 버튼이 조용히 무시됩니다 → **먼저 영상/검출이 보이게** 한 뒤 클릭.
- (GUI 창은 키보드 `t` 가 안 먹습니다. 반드시 **버튼**으로.)

### 방법 B — 키보드 앱
```bash
bash ~/demo_capture.sh
```
- 카메라 창에서 키보드 **`t`** 키를 누릅니다.

> **두 방법 모두**, 트리거 후에는 똑같은 **"Manual Tagging (SAM)"** 창이 뜨고
> 이후 조작(박스 드래그 → 점 보정 → 숫자키 확정 → Enter 저장)은 **완전히 동일**합니다.
> 아래 3~9번은 그 창에서의 공통 조작입니다.

---

## 2. 전체 흐름 한눈에

```
화면 보기 → (r: 관심영역 자르기) → d: 검출 → t: 라벨 시작
   └─ 객체마다: 박스 드래그 → (점으로 다듬기) → 숫자키로 클래스 확정
   → Enter: 저장 → 다음 장면으로 반복
```

---

## 3. 키 / 마우스 치트시트

**라벨링 켜기 (실행 도구별)**
| 도구 | 라벨링 시작 |
|---|---|
| **GUI** (`demo_gui.sh`) | 왼쪽 **`✎ 라벨링(SAM)` 버튼 클릭** (영상이 떠 있을 때) |
| **키보드앱** (`demo_capture.sh`) | **`t`** 키 |

**키보드앱 메인 화면 키** (GUI는 해당 버튼으로)
| 키 | 동작 |
|---|---|
| `d` | 현재 화면 검출(어떻게 잡는지 확인용) |
| `r` | 관심영역(ROI) 드래그 지정 / ESC=전체 |
| `t` | **라벨링 시작** (현재 화면 정지) |
| `q` | 종료 |

**라벨링 창("Manual Tagging (SAM)")**
| 입력 | 동작 |
|---|---|
| **좌클릭 드래그** | 객체를 감싸는 **박스** → SAM이 마스크 자동 생성 |
| **좌클릭(점)** | 마스크에 **포함**할 곳 추가 (초록 점) |
| **우클릭(점)** | 마스크에서 **제외**할 곳 추가 (빨강 점) |
| **숫자키 `0`~`3`** | 마스크를 그 **클래스로 확정** (0=Box, 1=Tote, 2=Wrap, 3=Pallet) |
| `z` | 방금 확정한 라벨 **하나 취소** |
| `Enter` | **저장**하고 라벨 종료 |
| `ESC` | 저장 안 하고 취소 |
| `p` | 폴리곤 모드 토글(SAM이 잘 안될 때, 아래 5번) |

---

## 4. 단계별 (기본 = SAM 방식)

1. 라벨할 장면을 비추고 **라벨링 시작**(GUI=`✎ 라벨링(SAM)` 버튼 / 키보드앱=`t`) → "Manual Tagging" 창에서 화면이 멈춥니다.
2. 객체 위에 **마우스 좌클릭 드래그로 박스**를 그립니다 → SAM이 **노란 외곽선 마스크**를 만들어줍니다.
3. 마스크가 부족/넘치면 다듬기:
   - 빠진 부분: 그 위를 **좌클릭**(초록 점=포함)
   - 잘못 들어온 부분: 그 위를 **우클릭**(빨강 점=제외)
   - 점을 찍을 때마다 마스크가 갱신됩니다. 콘솔에 `mask updated (score …)` 표시.
4. 마스크가 객체를 잘 덮으면 **클래스 숫자키**를 누릅니다:
   `0`=Box, `1`=Tote, `2`=Wrap, `3`=Pallet → 그 색으로 칠해지며 확정.
5. **한 화면에서 여러 객체**를 2~4번 반복해 확정할 수 있습니다.
6. 잘못했으면 **`z`** 로 마지막 라벨만 취소.
7. 다 했으면 **`Enter`** = 저장. (아무것도 안 했으면 **`ESC`**)

> 저장되면 콘솔에 `N개 객체 저장됨 → …/sam_hard_…jpg` 가 뜹니다.

---

## 5. SAM이 잘 안 잡힐 때 — 폴리곤 모드

투명 토트/반사/복잡한 경계라 SAM 마스크가 영 별로면 수동으로 외곽선을 찍습니다:
1. **`p`** → 폴리곤 모드 ON
2. 객체 외곽을 따라 **좌클릭으로 점**을 찍습니다(우클릭=마지막 점 취소)
3. 점 3개 이상 찍고 **`f`** → 폴리곤 완성(마스크 생성)
4. **숫자키**로 클래스 확정 (이후는 동일)
5. `p` 다시 누르면 SAM 모드로 복귀

---

## 6. 클래스 구분 가이드

| 키 | 클래스 | 무엇 |
|---|---|---|
| `0` | **Box** | 일반 종이박스(골판지) |
| `1` | **Tote** | 플라스틱 토트/크레이트(주로 곤지암형) |
| `2` | **Wrap** | 슈링크랩으로 감싼 묶음 |
| `3` | **Pallet** | 팔레트(받침) — 박스 아래 받침대 |

헷갈릴 때: **윗면 재질·형태로 판단.** 랩으로 감겼으면 Wrap, 플라스틱 박스면 Tote.
애매하면 동료/담당자에게 확인(잘못 라벨하면 학습에 독이 됩니다).

---

## 7. 잘 모으는 팁

- **하드케이스 위주**: 모델이 못 잡거나 잘못 잡는 장면을 우선 (잘 잡는 건 굳이 많이 안 모아도 됨)
- **다양하게**: 각도·조명·겹침·가림이 다양할수록 좋음
- **윗면이 보이게**: 픽 대상은 윗면 기하를 쓰므로 윗면이 보이는 프레임이 유용
- **경계 깔끔하게**: 박스 끼리 붙어 있으면 점(포함/제외)으로 인접 박스가 안 섞이게 다듬기
- 한 번에 완벽히 말고, **여러 장면을 조금씩** 모으는 게 효율적

## 8. 저장 위치 & 회수

- 저장물 = `sam_hard_<시각>.jpg` + `_mask.png` + `.json` 삼중조
- 저장 폴더 = 데이터 폴더(환경변수 `DEPAL_DATA_DIR`, Thor 기본 `~/depal_data`)
- 4090으로 회수(예):
  ```bash
  scp 'dr@<수집PC_IP>:~/depal_data/sam_hard_*' ~/수집폴더/
  ```
- 이후 학습 파이프라인(`dr-onsite-ingest`)이 이 폴더를 읽어 데이터셋에 합칩니다.

## 9. 흔한 실수

- **GUI에서 `t` 키를 누름** → GUI는 키 안 먹음. **`✎ 라벨링(SAM)` 버튼**을 클릭해야 함.
- **GUI에서 영상 안 뜬 상태로 라벨 버튼 클릭** → 조용히 무시. 먼저 영상/검출이 보이게 한 뒤 클릭.
- **숫자키를 마스크 만들기 전에 누름** → 아무 일도 안 일어남. **마스크(노란선)부터** 만들고 숫자키.
- **박스 안 그리고 점부터 클릭** → "먼저 바운딩박스를 그리세요" 경고. 드래그 박스가 먼저.
- **저장 안 하고 종료** → `Enter` 안 누르면 저장 안 됨(ESC=취소). 반드시 `Enter`.
- **잘못된 클래스로 확정** → `z`로 취소 후 다시.
- 너무 큰 박스로 여러 객체를 한 번에 → 객체 **하나씩** 라벨.
